Hired

Description: Dit project is een interactief spelverhaal in de vorm van een sollicitatiegesprek. De speler navigeert door een interview via dialogen en uitgesproken keuzes, waarbij micro-agressies en impliciete vooroordelen onderdeel zijn van de interactie. Stem en stilte functioneren als spelmechaniek, waardoor spanning, macht en sociale druk voelbaar worden binnen een professionele setting.
